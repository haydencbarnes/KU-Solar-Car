# KU Solar Car

Repository for the KU Solar Car project.

## Wiki

**Historical archive:** the KU Solar Car student team at the University of Kansas wound down around **2022**. This repo holds a static HTML mirror of their public site—topic pages plus **`wiki/posts/`** (full blog posts).

Live site: https://haydencbarnes.github.io/KU-Solar-Car/

Open `wiki/index.html` in a browser, or serve the folder with any static file server.

Refresh the mirror (requires network):

`python3 -m pip install -r requirements.txt && python3 scripts/import_wix_content.py`
